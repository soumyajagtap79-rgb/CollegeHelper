# College Helper

College Helper is a simple web application designed to help college students manage their everyday academic activities in one place.

## Features

- 📚 Subject topics
- 📝 To-Do List
- ✅ Mark tasks as Done
- 🗑️ Delete tasks
- 🗓️ College Timetable
- 📊 Overall Attendance Calculator
- 📚 Subject-wise Attendance
- 💻 Simple and beginner-friendly dashboard

## Technologies Used

- HTML
- CSS
- JavaScript

## Live Demo

https://soumyajagtap79-rgb.github.io/CollegeHelper/

## Purpose

College students often need to manage subjects, assignments, timetable and attendance separately. College Helper brings these basic academic tools together in one simple dashboard.
